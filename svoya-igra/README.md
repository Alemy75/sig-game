# Своя игра

Локальная игра для Windows и macOS. Интернет во время игры не нужен. Для загрузки медиа и экспорта нужен установленный Node.js 20.19+ или 22.12+ (подходит Node.js 24 LTS). При первом запуске нужен интернет для установки Vite; затем игра работает локально.

## Запуск на Windows и macOS

В терминале из папки gamesig или svoya-igra выполните одну команду:

```text
node start.js
```

При первом запуске Node сам установит зависимости через npm-cli.js, без PowerShell-скриптов и shell-обёрток. Нужен интернет. При следующих запусках установка не повторяется.

Браузер откроется автоматически по адресу http://127.0.0.1:8787. Если не открылся, перейдите по этому адресу вручную. Не закрывайте терминал во время игры; остановка — Ctrl+C. Сервер доступен только на вашем компьютере.

Не нужно выполнять npm ci, npm start, bash или менять политику выполнения PowerShell. Node.js должен быть установлен вместе со стандартным npm. index.html напрямую открывать не нужно.

## Разработка и сборка

- `npm run dev` — Vite с автоматическим обновлением при изменении кода.
- `npm run build` — сборка интерфейса в `dist`.
- `npm run preview` — локальный запуск собранного интерфейса.
- `npm test` — проверки правил игры, медиа и интеграции Vite.

И dev, и preview используют API из `server.cjs` через плагин в `vite.config.mjs`. Медиа хранятся в исходной папке `svoya-igra/uploads` рядом с исходным index.html, не копируются в dist и сохраняются при повторной сборке. Папка dist сама по себе не включает сервер загрузки и экспорта: для переноса приложения переносите проект с uploads, package.json и package-lock.json; node_modules автоматически восстановится при запуске node start.js. Одновременно запускайте только один режим на порту 8787.

## Медиа, импорт и экспорт

Медиа сохраняются отдельными файлами в `uploads` рядом с `index.html`. JSON содержит относительные пути `uploads/…`. Имена файлов вычисляются по содержимому, поэтому одинаковые файлы не дублируются и не перезаписывают другие медиа.

Ограничения: 30 МБ на файл, 8 вложений к вопросу и отдельно 8 к ответу, 100 МБ медиа на пакет.

«Экспорт» скачивает ZIP с `package.json` и папкой `uploads`, содержащей медиа этого пакета. Для переноса на другой компьютер:

1. Распакуйте ZIP.
2. Скопируйте содержимое `uploads` в папку `uploads` рядом с `index.html` игры.
3. Запустите игру и нажмите «Импорт», выберите только `package.json`.

Для повторного импорта на том же компьютере, где медиа уже есть, достаточно выбрать JSON. Если файла не хватает, импорт сообщит об этом, сохранив текущий пакет. Старые JSON со встроенными медиа также поддерживаются: при импорте медиа автоматически извлекаются в uploads.

Ваш адаптированный шаблон находится в `dump.json`. Его медиа уже в uploads. Исходная встроенная версия сохранена в `../dump.embedded.backup.json`, переносимый архив — в `../dump-export.zip`.

Изменения вопросов и незавершённая партия автоматически сохраняются в браузере. При переходе с открытия index.html на локальный сервер сохранение браузера не переносится: импортируйте JSON. Медиа остаются на диске даже после очистки браузера. Удаление вложения из вопроса не удаляет файл с диска, поскольку он может использоваться другими пакетами.

## Игра

Создайте 2–4 команды. Ведущий выбирает вопросы, отмечает отвечающего и оценивает ответ. Есть обычные вопросы, «Кот в мешке», аукцион и финал. Кнопка «Отменить» исправляет последнее игровое действие; счёт можно редактировать вручную.

- Пробел — запустить или остановить таймер.
- 1–4 — выбрать команду на обычном вопросе.
- О — показать ответ.

Для телевизора включите дублирование экрана и полноэкранный режим.
